# Privacy Policy — Özbekça terilma v1.05

**Developer / Company:** ALHARITM (Sarvarbek Nazarov)  
**Effective Date:** October 28, 2026  
**Application Package ID:** `com.alharitm.uzbekfkeyboard`

## 1. Zero Data Collection Policy (Maʼlumotlar yigʻilmasligi)
**Özbekça terilma** ("the Application") is a 100% offline Android Input Method (Keyboard) developed by **ALHARITM**. 
We **DO NOT** collect, store, log, transmit, or share any personal data, keystrokes, passwords, credit card numbers, contacts, clipboard items, or device identifiers.

## 2. No Internet Permission (100% Offline Operation)
The Application does **not** request the `android.permission.INTERNET` permission in its Android Manifest. Therefore, it is technically impossible for the Application to transmit any typed text or user data to any external server or third party.

## 3. Permissions Used
* **`android.permission.VIBRATE`**: Used solely to provide haptic feedback (key press vibration) when enabled by the user.

## 4. Local Preferences
User preferences (selected keyboard theme, layout, font size, and bottom margin offset) are stored strictly locally on the user's device via Android `SharedPreferences` and never leave the device.

## 5. Children's Privacy & Security
The Application contains no advertisements, no analytics SDKs, no in-app purchases, and no tracking mechanisms. It is completely safe for users of all ages.
